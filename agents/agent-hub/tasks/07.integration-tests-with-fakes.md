# 07. Integration Tests With Fakes

## Deterministic Objective

This task is complete only when end-to-end tests prove fake Codex and fake
opencode can fire configured hooks into `agent-hubd`, store date-partitioned
events, and fetch those events in partition/offset order without touching host
Codex or opencode configuration.

## Required Implementation

- Build `cmd/fake-codex` in tests.
- Build `cmd/fake-opencode` in tests.
- Start `agent-hubd` with temp `AGENT_HUB_HOME`.
- Run fake runners with `--mock-config`.
- Fire hook commands into `agent-hub hook notify`.
- Fetch stored events through `agent-hub fetch --limit`.
- Set temp `CODEX_HOME`, `OPENCODE_CONFIG_DIR`, and runner path env vars.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/07-integration-tests-with-fakes/
```

At minimum, include these 12 runnable leaves:

1. `fake-codex/lifecycle-success` verifies started, prompt, and finished events.
2. `fake-codex/lifecycle-failure` verifies started and failed/error hook behavior.
3. `fake-codex/tool-events` verifies tool started and finished events are stored.
4. `fake-codex/batch-fetch` verifies all fake Codex events fetch in order.
5. `fake-opencode/lifecycle-success` verifies started, prompt, and finished events.
6. `fake-opencode/lifecycle-failure` verifies session error maps to failed.
7. `fake-opencode/tool-events` verifies tool before and after events are stored.
8. `fake-opencode/batch-fetch` verifies all fake opencode events fetch in order.
9. `mixed-runners/same-daemon` verifies both fake runners publish to one daemon.
10. `storage/date-partition-created` verifies `events/YYYY/MM/DD/events.jsonl` exists.
11. `cursor/independent-consumers` verifies two consumers have independent cursors.
12. `isolation/no-host-config-mutation` verifies no host config paths are written.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Required Isolation

Tests must set temp values for:

```text
AGENT_HUB_HOME
CODEX_HOME
OPENCODE_CONFIG_DIR
AGENT_RUNNER_FAKE_CODEX_PATH
AGENT_RUNNER_OPENCODE_PATH
```

Tests must not write to:

```text
~/.agent-hub
~/.codex
~/.config/opencode
```

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/07-integration-tests-with-fakes
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `08` until this task's doc-style test tree passes.
