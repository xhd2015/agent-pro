# 04. Implement agent-hubd Daemon

## Deterministic Objective

This task is complete only when `agent-hubd` runs as a local daemon, owns the
storage lock, exposes Unix-socket queue operations, rebuilds durable state on
startup, and shuts down without losing acknowledged events.

## Required Implementation

- Add daemon process entrypoint.
- Use Unix socket as primary transport.
- Add optional localhost HTTP transport behind a flag.
- Implement `Notify`, `Fetch`, `Status`, `Consumers`, `Sessions`, and
  `Partitions`.
- Acquire exclusive daemon/storage lock.
- Rebuild indexes and sessions on startup.
- Flush and release lock on shutdown.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/04-implement-daemon/
```

At minimum, include these 12 runnable leaves:

1. `startup/creates-socket` verifies daemon creates a Unix socket in hub home.
2. `startup/acquires-lock` verifies daemon owns an exclusive storage lock.
3. `startup/second-daemon-fails` verifies a second daemon cannot use same home.
4. `notify/appends-event` verifies notify appends and returns envelope metadata.
5. `notify/invalid-event-rejected` verifies invalid events do not append.
6. `fetch/default-limit-one` verifies default fetch returns one event.
7. `fetch/limit-ten` verifies `limit=10` returns up to ten events.
8. `fetch/peek-no-advance` verifies peek does not advance cursor.
9. `status/json-health` verifies status returns health and storage fields.
10. `restart/preserves-events` verifies restart keeps acknowledged events.
11. `restart/rebuilds-sessions` verifies restart rebuilds session projection.
12. `shutdown/releases-lock` verifies shutdown releases daemon lock.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/04-implement-daemon
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `05` until this task's doc-style test tree passes.
