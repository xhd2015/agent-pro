# 00. Adjust fake-codex Mock Config

## Deterministic Objective

This task is complete only when `cmd/fake-codex` accepts
`exec --json --mock-config <file>`, loads one shared fake-runner config schema,
emits exactly the configured Codex-style stdout events, fires exactly the
configured hook commands at deterministic lifecycle points, and preserves the
legacy `--script` and `FAKE_CODEX_SCRIPT` behavior.

## Required Implementation

- Add `--mock-config <path>` to `fake-codex exec`.
- Add env fallback `FAKE_CODEX_MOCK_CONFIG`.
- Keep `--script` and `FAKE_CODEX_SCRIPT` as legacy aliases.
- Implement mock fields: `version`, `runner`, `session_id`, `model`,
  `delay_ms`, `exit_code`, `stderr`, `ignore_hook_errors`, `hook_command`,
  `stdout_events`, and `hooks`.
- Support hook timings: `before_start`, `before_stdout`, `after_stdout`,
  `before_exit`, and `on_error`.
- Send each hook payload to the hook command on stdin as JSON.
- Replace `{{event}}` in `hook_command` with the configured hook event name.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/00-adjust-fake-codex/
```

At minimum, include these 12 runnable leaves:

1. `mock-config/stdout-single-event` verifies one configured stdout event is emitted.
2. `mock-config/stdout-multiple-events-order` verifies event order is preserved.
3. `mock-config/model-and-session-fields` verifies configured session/model fields are available to generated events or hooks.
4. `mock-config/stderr-success` verifies configured stderr is written when exit code is zero.
5. `mock-config/nonzero-exit` verifies configured exit code is returned and stderr is preserved.
6. `mock-config/delay-ms-zero` verifies zero delay does not sleep between events.
7. `hooks/before-start` verifies the `before_start` hook fires before stdout.
8. `hooks/before-stdout` verifies the `before_stdout` hook fires before the first stdout event.
9. `hooks/after-stdout` verifies the `after_stdout` hook fires after all stdout events.
10. `hooks/before-exit` verifies the `before_exit` hook fires before process exit.
11. `hooks/on-error` verifies the `on_error` hook fires for nonzero exit.
12. `legacy-script/compatibility` verifies existing `--script` behavior remains unchanged.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/00-adjust-fake-codex
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `01` until this task's doc-style test tree passes.
