# 06. Implement Hook Adapters

## Deterministic Objective

This task is complete only when `agent-hub hook notify` maps supported Codex,
fake-Codex, opencode, and fake-opencode native hook payloads into normalized
Agent Hub events with stable field extraction and stable errors for unsupported
events.

## Required Implementation

- Read native payload JSON from stdin.
- Support runner values: `codex`, `fake-codex`, `opencode`, and
  `fake-opencode`.
- Map Codex events: `SessionStart`, `UserPromptSubmit`, `Stop`, `PreToolUse`,
  `PostToolUse`, `PermissionRequest`, `SubagentStart`, and `SubagentStop`.
- Map opencode events: `session.created`, `message.updated`, `session.status`,
  `session.idle`, `session.error`, `tool.execute.before`,
  `tool.execute.after`, `permission.asked`, and `permission.replied`.
- Preserve the native payload under `payload`.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/06-implement-hook-adapters/
```

At minimum, include these 15 runnable leaves:

1. `codex/session-start` verifies `SessionStart` maps to `agent.session.started`.
2. `codex/user-prompt-submit` verifies `UserPromptSubmit` maps to `agent.prompt.submitted`.
3. `codex/stop` verifies `Stop` maps to `agent.session.finished`.
4. `codex/pre-tool-use` verifies `PreToolUse` maps to `agent.tool.started`.
5. `codex/post-tool-use` verifies `PostToolUse` maps to `agent.tool.finished`.
6. `codex/permission-request` verifies `PermissionRequest` maps to permission event.
7. `codex/subagent-start` verifies subagent start maps to session update.
8. `opencode/session-created` verifies `session.created` maps to started.
9. `opencode/message-updated` verifies prompt text extraction when present.
10. `opencode/session-idle` verifies `session.idle` maps to finished.
11. `opencode/session-error` verifies `session.error` maps to failed.
12. `opencode/tool-before` verifies tool before maps to started.
13. `opencode/tool-after` verifies tool after maps to finished.
14. `errors/unknown-runner` verifies unknown runner fails clearly.
15. `errors/unknown-event` verifies unknown event fails clearly.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/06-implement-hook-adapters
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `07` until this task's doc-style test tree passes.
