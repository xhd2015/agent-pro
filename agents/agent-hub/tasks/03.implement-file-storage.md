# 03. Implement File Storage

## Deterministic Objective

This task is complete only when the file storage layer appends and reads Agent
Hub event envelopes from date partitions, assigns deterministic partition-local
offsets, persists consumer cursors, rebuilds indexes, and projects session state
without using SQLite or any external database.

## Required Implementation

- Resolve `AGENT_HUB_HOME`.
- Append events under `events/YYYY/MM/DD/events.jsonl`.
- Assign zero-based partition offsets.
- Write and rebuild optional `events.idx`.
- Read batches from `{partition, offset}`.
- Cross date partitions during reads.
- Persist consumer cursors under `consumers/*.cursor.json`.
- Maintain materialized sessions under `sessions/`.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/03-implement-file-storage/
```

At minimum, include these 13 runnable leaves:

1. `append/first-event-offset-zero` verifies first event in a partition has offset `0`.
2. `append/second-event-offset-one` verifies second event in same partition has offset `1`.
3. `append/new-day-resets-offset` verifies next date partition starts at offset `0`.
4. `append/received-at-selects-partition` verifies `received_at` selects storage partition.
5. `read/single-partition-batch` verifies batch read within one partition.
6. `read/cross-partition-batch` verifies batch read crosses from one date to the next.
7. `read/missing-day-skipped` verifies missing date directories are skipped.
8. `cursor/save-load` verifies consumer cursor persists and reloads.
9. `cursor/advance-after-batch` verifies cursor advances after returned batch.
10. `index/rebuild-missing` verifies missing index rebuilds from JSONL.
11. `session/project-started` verifies session started event creates active session.
12. `session/project-finished` verifies finished event moves session to completed.
13. `recovery/rebuild-sessions` verifies session state rebuilds from event log.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/03-implement-file-storage
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `04` until this task's doc-style test tree passes.
