# 01. Create fake-opencode

## Deterministic Objective

This task is complete only when `cmd/fake-opencode` exists, supports the
opencode command surface used by this repo, emits deterministic opencode-style
JSONL from `--mock-config`, fires configured hook commands, and never reads or
writes host opencode configuration.

## Required Implementation

- Add `cmd/fake-opencode/main.go`.
- Support `fake-opencode run --format json --mock-config <path> "prompt"`.
- Support `--dir`, `--model`, and `--session` for compatibility.
- Support `fake-opencode models`.
- Add env fallback `FAKE_OPENCODE_MOCK_CONFIG`.
- Use the same fake-runner mock config schema as `fake-codex`.
- Emit JSONL compatible with `agent/cli/opencode/opencode.go`.
- Fire hooks from mock config only.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/01-create-fake-opencode/
```

At minimum, include these 12 runnable leaves:

1. `models/default-list` verifies `fake-opencode models` prints deterministic models.
2. `run/text-event` verifies a configured text event is emitted as JSONL.
3. `run/tool-event` verifies a configured tool event matches the existing parser shape.
4. `run/error-event` verifies a configured error event is emitted and affects stderr.
5. `run/session-flag` verifies `--session` sets or preserves session ID.
6. `run/model-flag` verifies `--model` is accepted and available to hooks.
7. `run/dir-flag` verifies `--dir` is accepted without touching host config.
8. `mock-config/env-fallback` verifies `FAKE_OPENCODE_MOCK_CONFIG` works.
9. `hooks/session-created` verifies configured `session.created` hook fires.
10. `hooks/message-updated` verifies configured `message.updated` hook fires.
11. `hooks/session-error` verifies configured `session.error` hook fires on failure.
12. `isolation/no-host-config` verifies no files are written under `~/.config/opencode`.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/01-create-fake-opencode
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `02` until this task's doc-style test tree passes.
