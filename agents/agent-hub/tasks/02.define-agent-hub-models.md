# 02. Define Agent Hub Models

## Deterministic Objective

This task is complete only when a shared Go model package defines the Agent Hub
normalized event, daemon envelope, partition cursor, fetch response, producer
metadata, and fake-runner mock config, with deterministic validation and JSON
round-trip behavior.

## Required Implementation

- Define normalized event fields: `event_type`, `runner`,
  `runner_session_id`, `workspace`, `model`, `prompt`, `occurred_at`, and
  `payload`.
- Define daemon envelope fields: `schema_version`, `event_id`, `partition`,
  `offset`, `received_at`, `producer`, and `event`.
- Define cursor fields: `partition` and `offset`.
- Define fetch response fields: `consumer_id`, `events`, `previous_cursor`,
  `next_cursor`, and `has_more`.
- Define fake-runner mock config fields used by tasks `00` and `01`.
- Add validation helpers with stable error messages.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/02-define-agent-hub-models/
```

At minimum, include these 12 runnable leaves:

1. `normalized-event/valid-minimal` verifies a minimal valid event passes validation.
2. `normalized-event/missing-event-type` verifies missing `event_type` fails.
3. `normalized-event/missing-runner` verifies missing `runner` fails.
4. `normalized-event/unknown-event-type` verifies unknown event type fails.
5. `normalized-event/payload-round-trip` verifies arbitrary payload JSON is preserved.
6. `envelope/valid-round-trip` verifies envelope JSON round-trips.
7. `envelope/missing-partition` verifies missing partition fails.
8. `envelope/negative-offset` verifies negative offset fails.
9. `cursor/valid-round-trip` verifies cursor JSON round-trips.
10. `cursor/bad-partition-format` verifies invalid partition format fails.
11. `fetch-response/empty-batch` verifies empty batch response serializes correctly.
12. `mock-config/hooks-round-trip` verifies fake-runner hooks round-trip.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/02-define-agent-hub-models
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `03` until this task's doc-style test tree passes.
