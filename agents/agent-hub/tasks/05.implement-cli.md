# 05. Implement agent-hub CLI

## Deterministic Objective

This task is complete only when the public `agent-hub` CLI implements the
documented daemon, producer, consumer, replay, and inspection commands with
stable JSON output and deterministic error behavior.

## Required Implementation

- Implement `daemon start`, `daemon stop`, and `daemon status`.
- Implement `notify --json` and `notify --file`.
- Implement `hook notify`.
- Implement `fetch --consumer-id --limit --peek`.
- Implement `replay --consumer-id --from`.
- Implement `status`, `consumers`, `sessions`, and `partitions`.
- Return stable JSON response shapes.

## Required Doc-Style Test Tree

Create runnable doc-style tests under:

```text
agents/agent-hub/tests/05-implement-cli/
```

At minimum, include these 14 runnable leaves:

1. `daemon/start-status-stop` verifies daemon lifecycle through CLI.
2. `daemon/status-json` verifies `daemon status --json` shape.
3. `notify/json-valid` verifies `notify --json` publishes one event.
4. `notify/file-valid` verifies `notify --file` publishes one event.
5. `notify/json-invalid` verifies invalid JSON fails before append.
6. `hook-notify/codex-session-start` verifies hook notify accepts Codex event.
7. `hook-notify/opencode-session-created` verifies hook notify accepts opencode event.
8. `fetch/default-limit` verifies default limit is one.
9. `fetch/limit-ten` verifies `--limit 10` returns a batch.
10. `fetch/limit-zero-invalid` verifies `--limit 0` fails.
11. `fetch/peek` verifies `--peek` does not advance cursor.
12. `replay/from-cursor` verifies replay resets cursor to requested position.
13. `inspection/consumers` verifies consumers command lists cursor files.
14. `inspection/sessions` verifies sessions command returns projected sessions.

Each leaf must have its own `SETUP.md` and `ASSERT.md`.

## Run Gate

After each code change, run:

```sh
go run ./agents/test-case-tree-runner test --rm agents/agent-hub/tests/05-implement-cli
```

If it fails, fix the code or doc-style tests and rerun the same command until it
passes. Do not start task `06` until this task's doc-style test tree passes.
